# LiveCircle

Android family location sharing app plus a lightweight Node.js relay.

The source lives in `work/LiveCircle`. Sensitive local values such as the real relay address, group code, map key, SSH keys, server runtime data, APK outputs, and SDK downloads are intentionally excluded from this repository.

See [work/LiveCircle/README.md](work/LiveCircle/README.md) for build and deployment notes.
